# 单步 FM 冲击优势：正式实验报告

日期：2026-10-25。状态：实验、同观测流评估、固定权重闭环和实测 P50 延时复核均已完成；本报告只汇总既有产物，不重新训练、不重新选模、不根据测试结果改动判据。

原始实验产物已先原样归档为提交 `be8ec11`；本报告、日志与入口文档在其后补充。完整数值表见 [TABLES.md](TABLES.md)，逐模型产物位于 `data0/`、`data1/`、`data2/`。

## 结论先行

预先登记的主比较是 **B（单步 FM）对 A（同构残差回归）**：要求冲击 RMSE 至少改善 10%，且背景 RMSE 恶化不超过 5%。

本轮结果：

- **主比较未通过。** B 对 A 的冲击 RMSE 仅改善 **1.58%**，固定模型配对轨迹区间为 **[0.43%, 2.63%]**，远低于 10% 门槛；背景 RMSE 反而恶化 **1.49%**（95% 区间 [-1.70%, -1.28%]）。
- **B 对 C（重复端点监督）也没有优势。** 冲击改善 **-0.19%**（即略差），区间 [-1.22%, 0.80%]；背景恶化 **3.01%**。
- **闭环同样没有看到 B 的收益。** B 的跟踪 RMSE 为 0.0046799，高于 A 的 0.0043803 和 C 的 0.0041600；B 对 A 的事件后 1 秒误差能量变化为 **-4.80%**（负值表示 B 更差），B 对 C 为 **-11.38%**。
- **原始残差在冲击区间仍最准。** 原始残差冲击 RMSE 0.498545、增广 Kalman 0.496254，均明显低于 B 的 0.733519；但它们的背景 RMSE 约 0.50，远高于 B 的 0.122315。这是“平滑去噪”与“冲击保真”的经典取舍。
- **等优化耗时对照 A_time 反而最好于 A/B/C。** A_time 冲击 0.702175、背景 0.113798，提示额外优化时间本身能带来改善，不能用“更新数相同”替代“计算预算相同”。
- 按预注册协议，B 未达到门槛，因此**不启动**零源噪声消融和 D 组“跨时间特征辅助残差回归”追加实验；本轮不能声称 FM 路径监督具有独立优势。

## 1. 研究问题

主问题：在同一数据、同一网络、相同一次前向部署下，加入随机中间状态的 FM 速度损失，是否改善冲击估计，且不以明显恶化背景去噪为代价？

次问题：这种估计差异能否转化为固定权重闭环跟踪收益？单步 FM 相对多步 FM 是否形成更好的精度/计算折中？

单步部署统一为：

```text
prediction = source + v_theta(source, condition, source, tau=0)
```

每次估计严格一次网络前向。`z=source`、`tau=0` 的输入特征在所有组保留，避免输入层或参数量变化。

## 2. 实验设计

### 2.1 三个同构核心组与参照

三组均为宽 128、两个残差块的 `WindowNet(flow=True)`，参数量 **86,296**，输入、归一化、24 点历史和 24 点目标完全相同。

| 组别 | 训练损失 | 目的 |
|---|---|---|
| A：同构残差回归 | `L_result` | 零 FM 主对照 |
| B：单步 FM | `L_result + L_FM` | 检验随机中间路径速度监督 |
| C：重复端点监督 | `L_result + L_delta` | 排除“额外整段 MSE 权重”的解释 |

其中：

```text
L_result = MSE(prediction, y) + 4*MSE(prediction[:,0], y[:,0])
L_FM     = MSE(v_theta(s, c, (1-tau)*s + tau*y, tau), y - s)   # 每样本随机 tau
L_delta  = MSE(v_theta(s, c, s, 0), y - s)
```

`L_delta` 数学上等于 prediction 的整段 MSE；C 不引入流路径，只改变端点损失的整段/当前分量相对权重。A 每次更新 1 次前向，B/C 各 2 次；中点 FM 每次更新 9 次、每次推理 8 次。

另设：

- **A_time**：从 A 的第 15,000 次更新继续训练，直到累计优化耗时可与同配对 B 相比；本轮到约 21,600–23,400 次更新。它拥有更多验证机会，作为“等优化耗时”补充对照，不混入主因果比较。
- **普通直接回归**、**4 步中点 FM**：仅在数据重复 0 上训练 3 个种子，作为工程参照。
- **原始残差、EMA、增广 Kalman**：同观测流滤波基线；Kalman 使用真实模型参数和噪声尺度，是理想信息条件下的参照。
- 闭环另有无补偿、原始残差补偿、原始残差限幅 ±3。

### 2.2 数据

- 3 套独立训练数据，编号 0/1/2；每套 360 条训练、144 条验证；三套共享同一个 720 条固定测试集。
- 每条轨迹 12 秒、`dt=0.02 s`、601 个采样点，完整窗口 stride=1，共 555 个窗口/轨迹。审计计数：训练 199,800 窗口，验证 79,920 窗口。
- 训练：60 条平滑背景 + 2 种冲击制度 × 3 种宽度 × 50 条。
- 验证：24 条平滑背景 + 2 × 3 × 20 条冲击。
- 测试：120 条平滑背景 + 2 × 5 × 60 条冲击 = 720 条。
- 训练宽度：20/80/200 ms；测试宽度：20/40/80/120/200 ms。40/120 ms 是宽度插值，不是完全未见冲击。
- 两种冲击制度：
  1. 固定冲量范围 `|J| ∈ [0.15, 0.35]`，幅值 `J / width`；
  2. 幅值与宽度独立，`|A| ∈ [0.5, 3]`。
- 每条冲击轨迹两个事件，一正一负、顺序随机，事件间隔至少 2 秒。
- 主实验使用准确 x/v、准确已知 m/c/κ、高斯加速度噪声 σ=0.5；未测试 x/v 测量噪声、参数失配、亚周期冲击或硬件在环。

### 2.3 训练与隔离

- 每个配对种子先生成一份相同参数，再复制给 A/B/C，保证同初始化。
- batch=128，AdamW 学习率 0.001，weight decay 1e-4，梯度裁剪 5，每模型 15,000 次更新，每 500 次验证。
- 所有组在归一化 source 上加入标准差 0.01 的独立高斯噪声；归一化、x/v/u、标签、验证/测试/部署不加此噪声。
- batch、源增强、tau 使用独立随机数流，避免 B 多抽 tau 改变后续 batch。
- 选模分数：`0.5 × 事件/分层等权冲击 MSE + 0.5 × 轨迹等权背景 MSE`；只用验证集，测试集不参与选模。
- 训练/验证/测试按完整物理轨迹隔离；三套训练数据之间也不重叠。

### 2.4 统计

- 以整条测试轨迹为配对重采样单位，5,000 次 bootstrap；同一物理轨迹的两个事件及各模型预测一起重采样。
- 主比较 B 对 A，B 对 C 用于机制解释；两项冲击比较各给 97.5% 双侧区间（Bonferroni，合计至少 95%），背景与闭环给 95% 区间。
- 层级重采样（训练数据重复 × 配对种子 × 测试轨迹）仅作探索性展示；只有 3 个外层数据重复，不能当作精确总体保证。
- 工程门槛在训练前固定：冲击改善至少 10%，背景恶化不超过 5%。

### 2.5 闭环与延时

- 冻结第一阶段全部主模型权重，接入完全相同的 PD 控制器；不按闭环结果重选权重。
- 零额外延时为主；另用各模型自身的公开 B=1 API P50 软件延时做分段 ZOH 复核。
- 控制限幅 ±12，神经网络补偿限幅 ±12；原始残差补偿另设不单独限幅与限幅 ±3 两组，最终执行器均限幅 ±12。
- 闭环指标：事件起点后固定 1 秒的跟踪误差能量与峰值、`t≥1s` 全程 tracking RMSE、控制 RMS、Δu RMS、饱和比例。
- 延时测量：30 次预热后测 300 次，包含输入检查、归一化、网络推理、反归一化与控制限幅，不含传感器/通信/执行器 I/O。

## 4. 如何解释

### 4.1 单步部署在形式上就是残差回归

令 `f_theta(s,c) = v_theta(s,c,s,0)`，则 `prediction = s + f_theta(s,c)`。结果损失为：

```text
MSE(f_theta(s,c), y - s) + 4*MSE(f_theta(s,c)[0], y[0] - s[0])
```

因此 A（同构残差）与 B（单步 FM）的部署分支具有相同形式；B 多出的只是训练时随机 `tau` 的速度约束。本轮的同构对照正是为了检验这部分约束是否真的有用，而不是把“FM”标签当成收益来源。

### 4.2 计算预算不是噪声

A_time 在冲击和背景上都优于 A/B/C，说明在本任务中增加优化时间本身就能改善指标。B 相对 A 的 1.58% 冲击改善，明显小于 A_time 相对 A 的改善（约 5.8%）。因此不能用“同更新数”代表“同计算预算”，也不能把 B 的小幅优势归因于 FM 路径。

### 4.3 冲击保真与背景平滑的冲突

原始残差和 Kalman 的冲击 RMSE 约 0.50，远好于所有学习模型（0.68–0.77），但背景 RMSE 约 0.50，远差于学习模型（0.11–0.12）。这不是“网络失败”，而是不同目标下的取舍：

- 网络为了压低背景噪声，会平滑掉部分窄脉冲；
- 原始残差保留脉冲，但也保留传感器噪声；
- 闭环中原始残差补偿的跟踪 RMSE 为 0.00518，反而差于学习模型的 0.00416–0.00468，控制抖动（Δu RMS 0.845）也更大；
- 限幅 ±3 的原始残差补偿进一步变差（0.00551），说明简单限幅没有解决取舍。

因此，“冲击估计更准”不自动等于“闭环更好”，必须分别报告估计指标和控制指标。

### 4.4 EMA 退化为原始残差

三套验证集上 EMA 的选参均选中 α=1.0，因此 EMA 与原始残差数值完全相同。这说明在当前“冲击/背景各半”的验证目标下，平滑会明显牺牲冲击峰值；不是 EMA 实现有问题。Kalman 选中的过程方差为 10 或 100，也只带来很小的改善。该结果本身反映了任务目标对滤波器的强约束。

## 5. 预注册判据与实际结论

| 观察到的结果 | 本轮是否发生 | 可以说的话 |
|---|---|---|
| B 胜 A、也胜 C，多个数据重复方向一致 | 否（B 对 A 仅 +1.58%，B 对 C 为 -0.19%） | 不能声称路径速度监督有独立增益 |
| B 只胜 A、不胜 C | 接近：B 略胜 A，但不胜 C | 可能主要是端点权重/优化差异，不能突出 FM 机制 |
| B 胜学习基线，但原始残差冲击更准 | B 仅略胜 A，原始残差明显更准 | 即使有优势，也只是相对学习基线的折中优势 |
| B 只降低背景误差，冲击误差不降 | 否：B 背景更差、冲击仅小幅改善 | 不能声称冲击优势 |
| 估计更准但闭环不改善 | 否：估计仅小幅变化，闭环还略差 | 没有估计到控制的转化证据 |
| B 与 A/C 接近，B 训练更贵 | 是 | 优先更简单的同构残差方案 |

预注册协议规定：只有 B 在 A/C 两个对照上均达到门槛、且独立数据重复方向一致，才启动零源增强和 D 组追加验证。本轮未满足，因此：

- **未执行**零源噪声（source noise = 0）消融；
- **未执行** D 组“固定 z=s、随机 tau 的辅助残差回归”；
- **未进行** 测试驱动的额外调参、学习率搜索或检查点重选。

这不是实验失败，而是预注册规则按预期生效：不把一次未达门槛的结果继续包装成确认性优势。

## 6. 适用范围与限制

本轮**没有**覆盖：

- x/v 测量噪声进观测器或反馈控制器；
- 真实参数与名义参数失配；
- 三角/半正弦等未训练脉冲形状，随机亚周期相位，短于 20 ms 的冲击；
- 真实传感器尖峰与真实冲击的区分；
- 随机延时、长尾延时、通信抖动、硬件在环；
- 更多骨干网络、窗口长度、损失权重或学习率的系统搜索。

已有证据的边界：

- 3 套独立训练数据 × 3 个权重种子，仍不足以精确估计训练分布变化带来的不确定性；层级区间仅探索性。
- 测试集固定且对所有方法只评分一次，但没有做到“完全封存后只打开一次”的强隔离；子组和辅助指标均为探索性。
- 测试集的 40/120 ms 是训练宽度的插值，不是完全未见宽度。
- 直接回归与中点 FM 只在 data0 上训练，不能与 A/B/C 的三套数据均值做严格同分布比较。
- `A_time` 的更新数随机器负载变化，且拥有更多验证机会；它是计算预算对照，不是主因果组。
- 闭环是仿真中的冻结权重测试，不是在线学习；真值只用于训练标签和评分。
- 所有指标来自已知仿真模型，不能外推为真实系统的稳定性或实时性保证。

## 8. 结论

本轮最严格的同构实验没有支持“单步 FM 的随机中间路径速度监督能带来冲击优势”这一主张。B 相对 A 的冲击改善只有约 1.6%，背景反而变差，闭环也没有收益；B 相对 C 更不占优；原始残差在冲击区间仍最准，但背景和控制抖动代价明显。A_time 的结果进一步说明，计算预算本身就能解释一部分差异。

因此，当前证据更支持以下工程选择：

- 若目标是简单、低计算开销的扰动观测，**同构残差回归/直接回归**仍是合理默认；
- 若目标是冲击保真，**原始残差或 Kalman** 更值得作为参照，但必须同时评估控制抖动；
- 单步 FM 可以保留为研究假设，但不能仅凭本轮结果宣称优于残差回归；
- 下一轮应优先做闭环噪声/参数失配/延时的组合实验，以及观测驱动的原始残差融合，而不是在同一个测试集上继续调 FM。
