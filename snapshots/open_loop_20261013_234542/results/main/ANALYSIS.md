# 补充分析

## 配对轨迹 Bootstrap（中等高斯噪声）

先对每条测试轨迹的各训练种子 MSE 取均值，再以轨迹为单位配对重采样 5000 次；不是对高度重叠的窗口独立重采样。
正差值表示 A2AFM 的 RMSE 更低。这些区间仅描述当前仿真测试分布与训练种子集合，不覆盖真实系统迁移不确定性。

| 对照 | RMSE(对照) − RMSE(A2AFM) | 95% 区间 |
|---|---:|---:|
| raw | 0.33120 | [0.30972, 0.35297] |
| ema | 0.08927 | [0.07062, 0.10777] |
| local_poly | 0.13956 | [0.12779, 0.15165] |
| kalman | 0.10620 | [0.09481, 0.11813] |
| physics_backward | -0.12009 | [-0.13143, -0.11076] |
| regression | 0.00204 | [-0.00112, 0.00498] |
| fm_only | 0.06836 | [0.06089, 0.07592] |

## CPU 推理耗时

单样本，10 次预热、100 次测量；只包含网络和流积分，不含预处理/传感器 I/O。
