# 单步 FM 冲击验证：执行时冻结的规则

本文件在正式训练进行中、尚未生成或读取测试评分时写入。训练配置已由入口程序在训练开始前写入 `results/shock_validation/frozen_config.json`，来源文件 SHA-256 记录在 `provenance.json`。

## 范围与预算

- 主实验 A/B/C 各 3 套独立训练数据 × 3 个配对权重种子。每套 360 条训练、144 条验证，共享 720 条最终测试轨迹。窗口 stride=1，每条 555 个训练/预测窗口。
- 数据重复编号 0/1/2；训练种子 210000/211000/212000，验证 220000/221000/222000，测试 230000；权重种子 11/22/33。
- A/B/C 相同初始化、相同批次和源增强；随机 tau 使用独立流，不移动批次/增强随机序列。
- 网络参数 86,296；AdamW，学习率 0.001，weight decay 0.0001，batch 128，梯度范数裁剪 5；源噪声标准差为归一化单位的 0.01。每模型固定 15,000 次更新，每 500 次验证。无测试驱动的延长、学习率搜索或重选模型。
- 固定预算不等于证明数学收敛：报告验证曲线和最佳步数，保留预算内结论。
- A_time 从 A 的第 15,000 次更新继续，直到累计优化步骤耗时达到同配对 B 的耗时；保留 A 原有验证最佳模型，并允许延长阶段替换。仅匹配前向/反向/梯度裁剪/优化器耗时，不含验证、公共采样与磁盘保存。这个补充对照拥有更多验证机会，应一并披露。
- 普通直接回归和 4 步中点 FM 在数据重复 0 上各训练 3 个种子，作为工程参照；不混入跨 3 套数据的主因果比较。
- 3 个 CPU 训练进程，每进程 PyTorch 1 线程，使用本地 CPU，无 GPU。

## 数据及信息条件

每套训练为 60 条背景 + 2 种冲击制度 × 3 种宽度 × 50 条；验证为 24 + 2×3×20；测试为 120 + 2×5×60。每条冲击轨迹两个事件，符号一正一负且顺序随机；时刻广泛随机且至少相隔 2 秒。每个分层内 PD 与 DOB 收集各占一半；网络不参与收集。

宽度训练 20/80/200ms，测试 20/40/80/120/200ms。制度一 |J|∈[0.15,0.35] 且幅值 J/width；制度二 |A|∈[0.5,3] 与宽度独立。背景由 7 种纯/混合轨迹族组成。每条 12 秒、采样 20ms，植物精确 ZOH 推进，脉冲网格对齐。

主试验准确 x/v、准确已知 m/c/k、高斯加速度噪声 σ=0.5。所有学习方法同一输入，滤波方法知道真实参数/σ。EMA 只用残差；增广 Kalman 用 x/v/u/a，状态 [x,v,d]，d 随机游走，精确 x/v 用 1e-12 测量方差近似。滤波可保留无限过去状态，网络只有 24 点，因此仍非完全相同历史记忆。

EMA 候选 α=[.05,.1,.2,.35,.5,.7,.9,1]；增广 Kalman 扰动过程方差 q=[.001,.01,.1,1,10,100]，均按各数据重复验证集相同目标选参。

## 评分与统计

验证目标为 0.5×冲击 MSE + 0.5×背景 MSE。冲击先按事件、轨迹、制度×宽度分层等权，背景按轨迹等权。评分从 t=1s 开始，到窗口仍有完整未来标签的最后一刻；背景剔除脉冲及其后 0.5 秒。虽然预测 24 点，评分只用当前第一点。

主比较 B/A；B/C 用于机制解释。主表为每个训练重复各自 RMSE 的算术平均；所有重复的原始数值保留。改善率定义为 100×(1−mean_RMSE_B/mean_RMSE_reference)。工程门槛：冲击改善至少 10%，同时背景恶化不超过 5%。不能只凭均值越线就宣称门槛成立。

测试集分层、配对、整轨迹 bootstrap 5,000 次。同一物理轨迹的两个事件及各模型预测始终一起重采样。两项冲击比较各给 97.5% 双侧区间（Bonferroni，合计覆盖率至少 95%）；背景 95% 区间单独报告，作为工程护栏，而非额外确认性优越性主张。

另外对训练数据重复、其内配对种子、共同测试轨迹作层级重采样，展示训练变动；仅 3 个外层数据重复，层级区间是探索性，不视为精确总体置信保证。逐宽度和辅助事件指标均为探索性。原始残差也进入同观测流评估。

## 闭环

不论主比较结果正负，全部冻结主模型都做零额外延时闭环复测；不按闭环结果重选权重。沿用原有 PD、控制限幅 ±12，神经网络补偿限幅 ±12。原始残差补偿另设不单独限幅与限幅 ±3 两组（最终执行器均限幅 ±12）。闭环基线还有无补偿、EMA、增广 Kalman。

事件指标为从起点开始固定 1 秒的跟踪误差能量与峰值，另报 t≥1s 的全程 tracking RMSE、控制 RMS、Δu RMS 与饱和比例。真实轨迹受各自控制自然改变；外生扰动/参数/观测噪声样本配对。

训练结束后测公开 B=1 推理 API 的 300 次 P50/P95（30 次预热），核对实际网络调用数。各自主模型再使用自己的 P50 软件延时进行分段 ZOH 控制仿真；不把这个软件时间称为端到端硬件实时保证。

若 B 在 A/C 两个对照上均达到预定门槛、且独立数据重复方向一致，才启动零源增强和 D 辅助监督追加验证；未满足时不把更多调参当成同一次确认实验。其他噪声、亚周期脉冲、参数失配和硬件验证属于后续稳健性研究，不能在本轮报告中声称已完成。
